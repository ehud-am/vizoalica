# Quickstart: Basic Analytics Dashboard

1. Configure an administrator credential and two sources in separate projects.
2. Record accepted page views with repeated anonymous visitors across more than one day.
3. Open the protected dashboard for one source and verify its today, seven-day, and 30-day totals.
4. Confirm page views and unique users match the selected source only.
5. Confirm unauthenticated, invalid-period, cross-project, and raw-data requests are denied.
6. Confirm the rendered page and data response contain no visitor/session IDs, raw events, tokens,
or raw URL query values.
