# Vizoalica

Vizoalica aims to provide web analytics for product teams and website owners in the spirit of tools like Pendo, while staying open source, self-hosted, and inexpensive to deploy and operate.

The project goal is to make it practical to understand how people use a web product without locking analytics data into a proprietary platform or requiring costly infrastructure. Vizoalica should be easy to run, transparent by default, and suitable for teams that want ownership of their product analytics stack.
