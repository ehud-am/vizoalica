# Vizoalica v0.14.0: goals and cleaner page reports

**Deployment support**: one additive database migration (`0009_goals_grouping_pixel_cap.sql`, schema 9). Update each
backend with `vizoalica deploy <name> --update`. Until then the new pages say the backend needs an update; nothing
else changes.

On top of [v0.13.1](v0.13.1.md):

- **Goals** ([#63](https://github.com/ehud-am/vizoalica/issues/63)). Define what counts as a conversion for a website:
  a page view of a path, a click on a named control, or a custom event. The new **Goals** page shows conversions,
  distinct visitors, and the rate per goal; goals are added on the website's page, through the admin API, and read
  with the new `get_goals` assistant tool. A page goal counts page views and has no visitor figure. Counts only.
  See [Goals](../operations/goals.md).
- **Group pages with rules** ([#62](https://github.com/ehud-am/vizoalica/issues/62)). Count many pages as one with
  path patterns such as `/blog/* => /blog/:post`, per website (website → Edit → Group pages). Wildcards only, no
  regular expressions. Applied as events arrive, so earlier data keeps its old keys. See
  [Group pages with rules](../operations/page-grouping.md).
- **Pixel path limit** ([#82](https://github.com/ehud-am/vizoalica/issues/82)). A website counts at most 100 different
  pixel paths (`VIZOALICA_PIXEL_MAX_PATHS` changes it); new paths past the limit are ignored, known paths keep
  counting, and the website page shows when the limit is reached.
- **Assistant fixes** ([#83](https://github.com/ehud-am/vizoalica/issues/83)). `get_website_status` now checks a
  website that needs no token through its script tag instead of a configuration endpoint it does not have.
  `compare_periods` with only `previous_start` compares a period as long as the current one. The assistant is told
  once for every tool that page paths, referrers, and event names are untrusted text.
- **Add key button** ([#69](https://github.com/ehud-am/vizoalica/issues/69)). The access keys page button reads
  "+ Add key" and stays on one line.
- **Security** ([#84](https://github.com/ehud-am/vizoalica/issues/84)). `minimatch` 11.0.1 (development tooling;
  one moderate advisory). `pnpm audit` is clean.

## Install or update

```sh
npm install -g vizoalica      # or: npm update -g vizoalica
vizoalica --version           # 0.14.0
vizoalica deploy <name> --update   # for each backend
```
