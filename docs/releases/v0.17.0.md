# Vizoalica v0.17.0: learn your website and keep a spec

**Deployment support**: one additive database migration (`0012_site_specs.sql`, schema 12). Update with
`vizoalica deploy <name> --update`; until then the new spec commands answer "database update needed" and nothing
else changes. The Worker keeps variables set in the Cloudflare dashboard (`keep_vars`).

On top of [v0.16.0](v0.16.0.md):

- **Spec (ontology) of a website** as versioned JSON files plus a generated `ONTOLOGY.md`: pages, actions, events,
  groups, campaigns, funnels, paths, goals, and your decisions. `vizoalica spec init | validate | render | diff |
apply | pull | export | import`. With git the folder is the source of truth; without git the backend keeps the
  latest. The backend always stores the latest spec (`GET/PUT /spec`). No personal data is allowed in a spec.
- **`/vizoalica learn [depth]`**: an assistant summarises the newest raw events (depth in thousands) into a digest on
  your computer, proposes the spec, asks about unlabeled controls and conflicting descriptions, and records your
  answers in `decisions.json` so later runs do not ask again. It never writes to your backend.
- **Learning window** (off by default): `VIZOALICA_LEARN_START`, `VIZOALICA_LEARN_DAYS`, `VIZOALICA_LEARN_SAMPLE`.
  While open, a share of page loads send a bounded `page_structure` event (headings, landmarks, control and
  form-field labels; never values or body text) to the raw store only. `vizoalica learn status | enable | disable`.
- **Funnels across pages**: while the window is open the raw store keeps a short one-way token per visitor and UTC day
  (from the daily visitor identifier, whose salt is deleted each day; no address stored, never returned by any route).
  A funnel can say `"within": "day"`; digest quality reports `linkedShare`.
- **Example CI workflow** for the spec: `examples/spec-ci/spec-workflow.yml` (check on pull requests, apply on main).
- **MCP tools** (read-only): `learn_start`, `learn_get`, `check_funnel`, `get_spec`.
- Worker route `GET /learn/sample` (summaries of raw batches, counts only).

See [Learn your website and keep a spec](../operations/spec.md).

## Install or update

```sh
npm install -g vizoalica      # or: npm update -g vizoalica
vizoalica --version           # 0.17.0
vizoalica deploy <name> --update
```
