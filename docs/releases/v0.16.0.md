# Vizoalica v0.16.0: events page cleanup and console `open`

**Deployment support**: none. No database migration; no backend update needed.

On top of [v0.15.0](v0.15.0.md):

- **Events page.** The per-interval "Exact event values" table is gone. The chart, the events list and the top
  pages (URLs) remain.
- **Console `open` command.** In the terminal running `vizoalica console`, type `o` or `open` and press Enter. An
  open console tab is reloaded; if none is open, a new browser tab opens. This also works when started with
  `--no-open`.

## Install or update

```sh
npm install -g vizoalica      # or: npm update -g vizoalica
vizoalica --version           # 0.16.0
```
