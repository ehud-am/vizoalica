# Vizoalica v0.17.2: clearer command names

**Deployment support**: none. No database migration; no backend update needed. Update the CLI with
`npm update -g vizoalica`. The Worker variables (`VIZOALICA_LEARN_START`, `VIZOALICA_LEARN_DAYS`,
`VIZOALICA_LEARN_SAMPLE`) are unchanged.

On top of [v0.17.1](v0.17.1.md). These are breaking renames with no redirects:

- `vizoalica learn status | enable-guide | disable-guide` is now `vizoalica learning-mode status | enable | disable`,
  so it no longer shares a name with the assistant command `/vizoalica learn`. `enable` and `disable` still only
  print the steps and change nothing.
- `--days` of `enable` is now `--duration` (days, 1 to 90).
- `vizoalica mapping export | apply` and the guided-setup page are removed. Use `/vizoalica learn` and
  `vizoalica spec apply`, which cover page names, groups, grouping rules and goals as well as actions, events,
  campaigns, funnels and paths. The MCP tool `get_inventory` stays.

## Install or update

```sh
npm install -g vizoalica      # or: npm update -g vizoalica
vizoalica --version           # 0.17.2
```
