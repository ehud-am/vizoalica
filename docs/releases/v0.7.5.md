# Vizoalica v0.7.5 — Top pages name their website

**Deployment support**: no D1 schema change. The backend (Worker) changed: update a running backend to get
website names in Top pages. A console on 0.7.5 against an older backend keeps working and shows bare paths.

A small feature release on top of [v0.7.4](v0.7.4.md):

- **Top pages name the website each page belongs to.** In a project with more than one website, viewed as All
  websites, each page reads like `/ · Blog`, and the same path on two websites is two rows instead of one merged
  count. With a single website selected, or in a project with one website, nothing changes.
- **For maintainers:** the docs site's analytics is on by default; visitors can turn it off, and Global Privacy
  Control and Do Not Track are honored. This concerns this repository's own docs site only.

## Install or update

```sh
npm install -g vizoalica      # or: npm update -g vizoalica
vizoalica --version           # 0.7.5
```

Then update the backend so it returns website names: see
[Update an existing backend](../operations/cloudflare.md#update-an-existing-backend).
