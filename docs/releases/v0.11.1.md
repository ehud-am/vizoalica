# Vizoalica v0.11.1: dependency updates

**Deployment support**: no database migration. The backend (Worker) is rebuilt with updated dependencies but its
behavior is unchanged. Updating is optional; if you want the rebuilt Worker, use
`vizoalica deploy <name> --update`, or all of them with `vizoalica deploy --update --all`.

On top of [v0.11.0](v0.11.0.md):

- **Dependencies**: `wrangler` 4.150.0, `vite` 8.3.4, `zod` 4.6.7, `prettier` 3.9.10, `@typescript-eslint` 8.71.2,
  `@testing-library/user-event` 14.6.8, `@playwright/test` 1.64.0, and the CI action `reviewdog/action-actionlint`
  1.80.2.
- **No change** to the console, the SDK, the reports, or the data collected.
- **Known issues carried over** from 0.11.0 are listed in `specs/022-utm-campaign-report/tasks.md`. One moderate
  advisory in `fast-uri` (through `ajv`) remains; no update clears it yet.

## Install or update

```sh
npm install -g vizoalica      # or: npm update -g vizoalica
vizoalica --version           # 0.11.1
```
