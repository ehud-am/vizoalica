# Vizoalica v0.13.1: README pixel settings

**Deployment support**: no database migration and no change to the backend. Nothing to update on a running backend.

On top of [v0.13.0](v0.13.0.md):

- **One website key for the README pixel.** The pipeline fills the pixel in the README from the repository variables
  `VIZOALICA_INGEST_ENDPOINT` and `VIZOALICA_WEBSITE_KEY`, the same ones the docs site uses.
  `VIZOALICA_README_WEBSITE_KEY` is no longer read; delete it if you set it.
- **Two pages you can tell apart.** The repository README counts under `/readme`, the npm README under
  `/npm/readme`. See [Count views of a README](../operations/pixel.md).
- The filled block keeps the blank lines Prettier writes, so the README stays formatted after the workflow commits it.
- Dependency updates (`reviewdog/action-actionlint`, minor and patch group).

## Install or update

```sh
npm install -g vizoalica      # or: npm update -g vizoalica
vizoalica --version           # 0.13.1
```
