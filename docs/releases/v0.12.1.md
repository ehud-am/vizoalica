# Vizoalica v0.12.1: security and dependency updates

**Deployment support**: no database migration. The backend (Worker) is rebuilt with updated dependencies but its
behavior is unchanged. Updating is recommended; use `vizoalica deploy <name> --update`, or all of them with
`vizoalica deploy --update --all`.

On top of [v0.12.0](v0.12.0.md):

- **Security**: `undici` 7.30.1, `fast-uri` 3.1.9 and `ip-address` 10.7.4 clear all open Dependabot alerts that have a
  fix. `pnpm audit` reports no known vulnerabilities.
- **Tooling**: `vitest` and `@vitest/coverage-v8` 4.1.12, which also unblocks Dependabot security updates.
- **Documentation site**: sends unsigned events, with no token endpoint or signing secret; the workflow accepts
  `VIZOALICA_WEBSITE_KEY`.
- **Accessibility**: the docs search button and the console install-path tabs are named by their visible text.
- **No change** to the SDK, the reports, or the data collected.

## Install or update

```sh
npm install -g vizoalica      # or: npm update -g vizoalica
vizoalica --version           # 0.12.1
```
