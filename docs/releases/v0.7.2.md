# Vizoalica v0.7.2 — 0.7.0, published to npm

**Deployment support**: no D1 schema change and no backend change. A backend deployed with 0.7.0 or 0.7.1 needs
nothing: the console and the Worker match on 0.7.

This is [v0.7.0](v0.7.0.md) as it was meant to ship. Neither 0.7.0 nor 0.7.1 could be published to npm: the
first because the package build relied on a workspace package having been compiled, the second because the
release workflow installs the newest npm, and npm 12 prints `npm pack --json` in a different shape than the
package check expected. 0.7.2 fixes both and changes nothing else; it is the first npm version with the 0.7
features:

- `npm install -g vizoalica`, then `vizoalica env add prod` deploys a backend (or connects one), explaining each
  question, and `vizoalica console` opens the console.
- `vizoalica deploy`, `vizoalica rotate`, and `--verbose` on any command.

See the [v0.7.0 notes](v0.7.0.md) for everything in this release, and upgrading.

## Install or update

```sh
npm install -g vizoalica      # or: npm update -g vizoalica
vizoalica --version           # 0.7.2
```
