# Vizoalica v0.7.4 — Current dependencies

**Deployment support**: no D1 schema change and no backend change. A backend deployed with 0.7.0 to 0.7.3 needs
nothing. Snippets, workflow variables and environments from earlier versions keep working unchanged.

A small maintenance release on top of [v0.7.3](v0.7.3.md):

- **Development dependencies are current**, including jsdom 30, eslint 10.11, wrangler 4.136 and the `actionlint`
  step in CI. The package's runtime code is unchanged.
- **The Geography table's location names read correctly to assistive technology** ("Germany DE"): the space between
  the name and its code no longer depends on how a DOM implementation treats it.
- **For maintainers:** the docs site's analytics defaults the SDK path, token path and consent state like the deploy
  workflow does, so it needs five settings instead of eight, and its workflow reads the identifying values from
  secrets. This concerns this repository's own docs publish only.

## Install or update

```sh
npm install -g vizoalica      # or: npm update -g vizoalica
vizoalica --version           # 0.7.4
```
