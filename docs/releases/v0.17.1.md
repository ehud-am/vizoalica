# Vizoalica v0.17.1: see and change the spec, and a clearer pitch

**Deployment support**: none. No database migration; no backend update needed. Update the CLI with
`npm update -g vizoalica`. The console page needs the new CLI; the backend is unchanged.

On top of [v0.17.0](v0.17.0.md):

- **See the latest spec**: `vizoalica spec show <environment> [--json]` prints it, and the console has a view-only
  **Manage > Spec** page. `vizoalica learn status` now says what to do next.
- **CLI review** (see the changelog): `vizoalica learn enable | disable` are now `enable-guide | disable-guide`
  (they only print steps), `--sample` is `--sample-percent`, `--option=value` works everywhere, `<command> --help`
  works for every command, and help says what each command changes.
- **Docs answer the common questions**: how a spec is created (you ask `/vizoalica learn`, then `spec apply`), how to
  see it, and how to change it without git (`spec pull`, edit, `spec apply`).
- **`VIZOALICA_LEARN_SAMPLE` explained**: it is the percent of visits that describe their pages, not a count.
- **README, npm README, docs and site** now cover learning, and "Why Vizoalica" leads with self-deployed, data stays in
  your account, free to deploy, and AI-first self-learning in place of hand-maintained site metadata.

## Install or update

```sh
npm install -g vizoalica      # or: npm update -g vizoalica
vizoalica --version           # 0.17.1
```
