# Vizoalica v0.8.0 — Ask an AI assistant about your analytics

**Deployment support**: no D1 schema change. The backend (Worker) changed: the undocumented `/mcp` endpoint is
removed. Update a running backend with `vizoalica deploy <name> --update`. A console on 0.8.0 keeps working against
a 0.7.x backend, and Health reports that an update is available.

The first release with AI support, on top of [v0.7.5](v0.7.5.md):

- **`vizoalica mcp`**: a local, read-only MCP server for Claude Code, Claude Desktop, Codex, Cursor, or any
  MCP client over stdio. It reads analytics and health from every environment in `vizoalica env list`, and
  every answer names the environment it came from. Secrets stay in the `vizoalica` process.
  `vizoalica mcp install --client claude-code|claude-desktop|codex|cursor` adds it to a client.
- **A Vizoalica skill** that teaches the assistant setup, health, operations and analytics.
  `vizoalica skill install --client claude-code|codex` installs it; for Claude Desktop or claude.ai, upload
  `vizoalica-skill.zip` from this release. See [Use Vizoalica with AI](../operations/ai.md).
- **`vizoalica deploy <name> --update`** updates a backend created by `vizoalica deploy` to the installed
  version: packaged Worker, pending migrations, data and secrets kept, and a check that the environment still
  works.
- **Alpha feedback in the console**: an Alpha badge, and a **Send feedback** link in the footer that opens a
  GitHub Discussion with the console version and current screen filled in, and nothing else.
- **Removed**:
  - `pnpm vizoalica backend`: use `vizoalica deploy <name> --apply` or `--update`.
  - `pnpm vizoalica deploy-pages`: use `wrangler pages deploy`.
  - The Worker's `/mcp` endpoint: use `vizoalica mcp`.

## Install or update

```sh
npm install -g vizoalica      # or: npm update -g vizoalica
vizoalica --version           # 0.8.0
vizoalica deploy prod --update
vizoalica mcp install --client claude-code
vizoalica skill install --client claude-code
```

See [Update an existing backend](../operations/cloudflare.md#update-an-existing-backend).
