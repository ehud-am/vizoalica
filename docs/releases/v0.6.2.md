# Vizoalica v0.6.2 — A quieter console start, and current dependencies

**Deployment support**: no D1 schema change and no backend change; nothing to redeploy on Cloudflare.
Pull this release and restart the console to get the change. Websites need no SDK update.

**Compatibility**: none broken. The generated website-workflow reference now points at `v0.6.2`.

Starting the console through OneCLI printed `UNDICI-EHPA: EnvHttpProxyAgent is experimental` every
time. OneCLI injects proxy settings, which makes Node's built-in fetch switch on that agent and warn.
Exactly that one warning is now silenced in the processes started through OneCLI (the console,
`pnpm vizoalica verify`, and `purge`), and any `NODE_OPTIONS` you set yourself is kept. Other warnings
still show.

The development toolchain moved forward: TypeScript 6, ESLint 10, Vite 8 (the console now builds with
its Rolldown bundler), React 19.3, Wrangler 4.134, and a group of smaller updates. TypeScript 6 needed
two small settings (`types: ["node"]` in the shared tsconfig, and `--ignoreConfig --types node` for the
examples check). `@types/node` deliberately stays on version 22, the oldest Node the project supports,
so code cannot use APIs that are missing on the runtime users are told to run. Nothing here changes
what the SDK, the Worker, or the console do.
