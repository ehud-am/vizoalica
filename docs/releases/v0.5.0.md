# Vizoalica v0.5.0 — Modern developer console

**Migration required**: none. Keep every existing migration through
`0005_dashboard_visual_refresh.sql` applied.

**Compatibility**: no breaking analytics, ingestion, website-management, or credential contract
changes. The existing browser SDK remains compatible.

Vizoalica 0.5.0 introduces a production V-and-analytics identity, dedicated light/dark lockups, a
responsive developer-focused console, and a guided `pnpm ops` workflow for running the private
console and deploying existing Direct Upload Pages sites.

The guided workflow deliberately keeps three credential paths separate: approval-gated
Worker/D1/R2 deployment, native Wrangler Pages uploads, and OneCLI-held Worker administrator access
for the local console. A Pages target is displayed before upload and requires its exact project
name as confirmation.

The release was validated with formatting, lint, type checking, 408 unit/integration tests,
coverage above the repository's 90% line/branch gates, a complete production build, six Chromium
responsive/accessibility scenarios, a production dependency audit, and secret scans of reachable
Git history and the exact publishable tree.

This release does not contain Cloudflare account credentials and does not trigger deployment. A
self-hosting operator decides whether and when to deploy it.

See the [changelog](../../CHANGELOG.md), [guided operations guide](../operations/ops-cli.md), and
[Cloudflare installation guide](../operations/cloudflare.md) for details.
