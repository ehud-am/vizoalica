# Vizoalica v0.5.0 — Modern developer console

**Deployment support**: fresh deployments only. Apply the single `0001_initial.sql` baseline to a
new empty D1 database. This release does not upgrade or preserve an existing Vizoalica database.

**Compatibility**: no breaking analytics, ingestion, website-management, or credential contract
changes. The existing browser SDK remains compatible.

Vizoalica 0.5.0 introduces a production visual identity, dedicated light/dark lockups, a responsive
developer-focused console, and three deployment steps: deploy one customer backend, configure each
operator using either supported credential method, and activate each website.

The workflows deliberately keep three credential paths separate: backend deployment, native
Wrangler/Git website deployment, and either directly held or OneCLI-injected Worker administrator
access for the local console. Mutating targets remain reviewable and explicitly approved.

The release was validated with formatting, lint, type checking, 418 unit/integration tests,
coverage above the repository's 90% line/branch gates, a complete production build, six Chromium
responsive/accessibility scenarios, a production dependency audit, and secret scans of reachable
Git history and the exact publishable tree.

This release does not contain Cloudflare account credentials and does not trigger deployment. A
self-hosting operator decides whether and when to deploy it.

See the [changelog](../../CHANGELOG.md), [guided operations guide](../operations/onecli.md), and
[Cloudflare installation guide](../operations/cloudflare.md) for details.
