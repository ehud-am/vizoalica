# Vizoalica v0.15.0: guided setup with an AI assistant

**Deployment support**: one additive database migration (`0011_page_labels.sql`, schema 11). Update each backend with
`vizoalica deploy <name> --update`. Until then a Worker keeps working; guided setup answers "database update
needed".

On top of [v0.14.1](v0.14.1.md):

- **Guided setup.** Deploy, let Vizoalica collect, then ask an AI assistant on your computer to propose page names,
  groups, grouping rules and goals. `vizoalica mapping export` gives it an inventory; it writes a mapping file; you
  review it; `vizoalica mapping apply` shows a diff and applies it. The assistant never writes to your backend, and
  nothing is removed. See [Guided setup](../operations/guided-setup.md).
- **Page names and groups** apply to everything already counted and can be changed or removed at any time. Grouping
  rules still apply to new events only, so the preview lists the page keys each rule would merge.
- **Assistant tool** `get_inventory` (read-only), and `pageNames` in `get_traffic_overview`.

## Install or update

```sh
npm install -g vizoalica      # or: npm update -g vizoalica
vizoalica --version           # 0.15.0
vizoalica deploy <name> --update   # for each backend
```
