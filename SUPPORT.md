# Getting help

Vizoalica is a small open-source project, so please pick the place that fits. It gets you an answer
sooner and helps the next person who has the same question.

| You want to…                                     | Go to                                                                                                    |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------------- |
| Set it up, or work out why something failed      | The [quick start](docs/get-started.md) and [troubleshooting](docs/operations/troubleshooting.md) first   |
| Ask a question or get advice                     | [Discussions → Q&A](https://github.com/ehud-am/vizoalica/discussions/categories/q-a)                     |
| Suggest an idea or talk about where it should go | [Discussions → Ideas](https://github.com/ehud-am/vizoalica/discussions/categories/ideas)                 |
| Show how you run it                              | [Discussions → Show and tell](https://github.com/ehud-am/vizoalica/discussions/categories/show-and-tell) |
| Report something that does not work              | [A bug report](https://github.com/ehud-am/vizoalica/issues/new?template=bug_report.yml)                  |
| Ask for a specific change                        | [A feature request](https://github.com/ehud-am/vizoalica/issues/new?template=feature_request.yml)        |
| Fix or improve something yourself                | [CONTRIBUTING.md](CONTRIBUTING.md)                                                                       |
| Report a vulnerability                           | [A private advisory](https://github.com/ehud-am/vizoalica/security/advisories/new), never a public post  |

When you ask for help, say which release you run and what you tried, and remove secrets, tokens,
account identifiers, and visitor data from anything you paste.
