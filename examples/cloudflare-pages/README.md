# Vizoalica Pages example

Run the complete [website activation journey](../../docs/operations/pages.md) once for each website. Copy
this folder to a separate website directory, register that website, fill in its public settings,
build/copy the SDK, and set the Pages signing secret. Do not deploy this unconfigured directory or
reuse another website's source identifiers.

- `functions/vizoalica/config.json.ts`: fail-closed version 1 public configuration adapter.
- `functions/vizoalica/ingest-token.ts`: scoped five-minute token endpoint.
- `public/index.html`: keyboard-accessible, consent-before-load static/dynamic test page.
- `public/vizoalica-loader.js`: generic dynamic loader generated by `pnpm browser-sdk:build`.
- `public/_routes.json`: runs Functions only for the config and token endpoints.
- `wrangler.example.toml`: six public browser variables plus server-only scope configuration; copy
  to `wrangler.toml` in your working copy.

The six browser values are plaintext public configuration. Keep signing and administrator secrets
out of this folder. Only the signing secret belongs in
Pages' encrypted secret configuration. The administrator secret stays with the Worker and local
client. On an existing website, merge configuration/routes rather than overwriting them.
